# lhg-ur-goal：研究目标与抽样设计

> 目标：调研开始前，先回答"研究什么、给谁用、多少样本才够"。
> 核心纪律：**研究问题一句话说不清不开工；样本量<30 不做定量结论。**

## 1. 何时使用

- 用户说"做个用户调研""了解一下用户"但说不清要什么 → 从第 2 步开始问
- 已有想法但研究问题模糊 → 做第 3 步澄清
- 样本量拍脑袋（"收 50 份吧"）→ 直接看第 5 步
- 结论没人用 → 回看第 4 步"决策用途"

## 2. 输入与输出

**输入**：用户的一句话诉求（如"新品卖不动，想知道为什么"）、可用资源（预算/时间/可触达用户数）。

**输出**：《研究目标卡》一页纸：研究问题 / 决策用途 / 成功标准 / 研究方法（问卷/访谈/混合）/ 样本计划。目标卡是后续所有步骤的"宪法"。

## 3. 分步方法论

### 第 1 步：把诉求翻译成研究问题

用户诉求通常是症状（"卖不动""流失高"），研究问题要翻译成可回答的疑问句：

| 用户诉求 | 翻译后的研究问题 |
|---|---|
| 新品卖不动 | 目标用户在购买决策中卡在哪一步？价格/信任/需求哪个是主因？ |
| 用户流失高 | 流失用户在离开前经历了什么？哪个触点是最后一根稻草？ |
| 想做新功能 | 目标用户现在用什么替代方案？我们的方案比它好在哪？ |

**检验标准**：研究问题必须能用"我们发现了 X"来回答。如果回答只能是"了解一下"，说明问题还太虚，继续追问。

### 第 2 步：明确决策用途（不许跳过）

问用户："这个结论出来，你会用来决定什么？"——决定下架哪个 SKU、决定要不要做这个功能、决定投放预算怎么分。**没有决策用途的调研不做**，因为没人会看报告。把决策用途写进目标卡，报告的"行动建议"章节直接对着它写。

### 第 3 步：选研究方法

| 方法 | 适合回答 | 样本量 | 成本 |
|---|---|---|---|
| 问卷 | "有多少""哪个更多"（是什么） | 100+（定量） | 低 |
| 一对一访谈 | "为什么""怎么想的"（为什么） | 8~15 人（定性） | 中 |
| 问卷+访谈（混合） | 先量化找现象，再深挖原因 | 问卷 100+，访谈 8+ | 中高 |

**选择逻辑**：先判断研究问题是"是什么"还是"为什么"。"是什么"用问卷，"为什么"用访谈，两个都要就用混合。**新手最常见的错**：用问卷问"为什么"——开放题回收率低、答案没法深挖，"为什么"必须访谈。

### 第 4 步：定成功标准

"调研成功"长什么样？示例：回收 300 份有效问卷、男女比例 1:1、输出 3 条可行动的发现。成功标准写进目标卡，结束时对照验收。没有成功标准，调研会无限拖延（"再多收 100 份吧"）。

### 第 5 步：定样本计划（四要素）

1. **样本量**：定量问卷 ≥100（做交叉分析建议 300+）；30 以下只能做定性参考，不许下定量结论。访谈 8~15 人，以"信息饱和"为停止标准（连续 2~3 场访谈不再出新观点即停）。
2. **抽样/招募方式**：随机抽样 / 配额抽样 / 滚雪球 / 用户池招募。写清是什么，因为"样本怎么来的"决定"结论能推广到谁"。
3. **配额结构**：性别、年龄、城市线级等关键维度的配额。不控制结构，样本会偏向最容易触达的人群。
4. **防废卷机制**：注意力检测题、作答时长下限、逻辑一致性校验，三选二以上。

### 第 6 步：输出目标卡（模板）

```markdown
## 研究目标卡
- 研究问题：一句话__
- 决策用途：结论用来决定__
- 研究方法：问卷/访谈/混合（为什么选这个）__
- 成功标准：__
- 样本计划：样本量__ 抽样方式__ 配额__ 防废卷__
- 资源约束：预算__ 时间__ 可触达用户__
```

目标卡经用户确认后锁定。后续任何"顺便加几个问题""再多访几个人"的请求，先对照目标卡：偏离研究问题 → 驳回或走变更。

## 4. 反模式

- **问题缝合怪**："顺便了解一下品牌认知、再问问竞品"——一个调研塞三个研究问题，每个都问不深。对策：一次调研一个核心问题，其他的排下期。
- **方法错配**：用问卷问"为什么流失"。对策：第 3 步选择逻辑，"为什么"必须访谈。
- **样本量拍脑袋**："收 50 份吧"——50 份做交叉分析每格没几个人。对策：第 5 步标准，100 是定量起步线。
- **为调研而调研**：没有决策用途，报告写完没人看。对策：第 2 步是硬门，答不上来不许开工。
- **无限加题**："再加 5 道题吧"——问卷超过 20 题（手机端），弃答率飙升。对策：每加一题必须删一题，或说明这题回答哪个研究问题。

### 附：研究目标卡填写示例

```markdown
## 研究目标卡（示例：新品满意度调研）
- 研究问题：购买过新品的用户中，满意度低的人卡在哪一步？价格/质量/服务哪个是主因？
- 决策用途：决定下季度产品改进的优先级排序（先改哪个）
- 研究方法：混合（问卷找现象→访谈挖原因）
- 成功标准：回收 300 份有效问卷；访谈 10 人（高低满意各半）；输出 3 条可行动的发现
- 样本计划：样本量 300；配额抽样（男女 1:1）；防废卷=注意力检测+作答时长
- 资源约束：预算 5000 元；时间 3 周；可触达用户=近 90 天购买用户约 2 万人
```

### 目标卡变更管理

目标卡锁定后想加问题/加样本，走变更单：谁提的、加什么、为什么、影响什么（题量/时间/预算），用户签字确认。**调研期间最常见的变更是"顺便加几道题"**——变更单的作用是让"顺便"的成本显性化：加 5 道题 = 弃答率上升 + 分析时间增加，很多人看到这就冷静了。

### 混合研究的顺序（先定性还是先定量）

| 顺序 | 适合 | 示例 |
|---|---|---|
| 先访谈→后问卷 | 探索未知领域，不知道该问什么 | 新品类、新人群，先访谈找维度，再问卷量化 |
| 先问卷→后访谈 | 已有假设，想验证+深挖 | 问卷发现 40+用户满意度低，访谈深挖为什么 |

**新手建议**：拿不准就选"先访谈后问卷"。访谈 5~8 人就能帮你校准问卷的方向，避免问卷发出后才发现"关键问题没问"。

### 资源不够时的最小可行调研

预算/时间都紧张时，最小可行方案：访谈 6~8 个典型用户（覆盖高/中/低满意），每场 30 分钟，当天整理。**6 场深访 > 50 份水问卷**——深度永远比数量重要，尤其在探索期。

> 记住一句话：调研的质量不取决于你问了多少人，而取决于你问的问题对不对、
> 问的人对不对、问完有没有行动。目标卡就是保证这三件事的工具。

### 目标卡评审会（15 分钟）

目标卡写完后，花 15 分钟过一遍，只问四个问题：

1. 研究问题如果回答了，算不算成功？（检验问题是否抓住了真诉求）
2. 决策用途是真需求吗？谁在等这个结论？（检验会不会没人看）
3. 样本计划现不现实？触达得到这么多人吗？（检验可行性）
4. 时间窗口内做得完吗？（检验排期）

四个都答得上来 → 锁定目标卡，进入问卷/访谈设计。答不上来 → 回去重写，不许带着疑问开工。

## 5. 自检与反馈

**质检门**（用本 skill 产出目标卡后自查）：

- [ ] 研究问题是一句话疑问句，能用"我们发现了 X"回答
- [ ] 决策用途具体（能说出"用来决定什么"）
- [ ] 研究方法与问题类型匹配（是什么→问卷，为什么→访谈）
- [ ] 样本计划四要素齐全，样本量达标（定量≥100）
- [ ] 成功标准可验收

**标准冒烟用例**：输入"想了解一下用户对新品的看法"，应追问出具体研究问题、决策用途、样本计划，而不是直接开始写问卷。

**反馈**：发现 bug 或有改进建议，以 `[QC] <一句话问题>` 为标题提交到 https://github.com/lhg-plugs/lhg-user-research/issues，正文写清"复现步骤 → 实际表现 → 期望表现"。
